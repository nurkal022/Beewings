# Методология BeeWings — автоматическая морфометрия крыльев медоносной пчелы

## Введение

Идентификация пород и подвидов *Apis mellifera* по морфометрии крыла — стандартный приём в пчеловодстве и таксономии с 1940-х годов. Данный проект реализует полный программный стек: ручную разметку, две модели глубокого обучения для автоматического обнаружения опорных точек (по схемам Алпатова и Тофильского), вычисление классических индексов (CI, DsA, RI) и пакетную обработку.

## Поддерживаемые методики

### 1. Методика Алпатова (8 / 12 точек)

Введена В. В. Алпатовым (1948) в СССР. **Линейная морфометрия** — индексы строятся как отношения длин определённых сегментов жилковой системы. Используется в российской и восточноевропейской пчеловодческой литературе.

**Базовый набор**: 8 точек на пересечениях основных жилок. **Расширение до 12 точек** включает медианно-кубитальные узлы.

**Главные индексы:**
- **Кубитальный индекс** (CI) — отношение двух сегментов жилок 3-й кубитальной ячейки
- **Дискоидальное смещение** (DsA, Goetze)
- **Радиальный индекс** (RI)
- **Хантеля** (Hantel)
- **Прибыльского** (PI)

### 2. Методика Тофильского (19 точек)

Анатолий Тофильский (Жешув, Польша, 2008+). **Геометрическая морфометрия** — точки выбраны так, что вокруг каждой можно вписать круг, касающийся жилок не менее чем в 3 точках (геометрически устойчивые). Анализ — через Procrustes superimposition + PCA + дискриминантный анализ.

Реализована в ПО **DrawWing** и **IdentiFly**, поддерживает классификацию **19 подвидов** и 4 эволюционных линий *Apis mellifera*. Современная преемница — **DeepWings** (2022, нейросетевая).

### Почему две системы не взаимозаменяемы

Несмотря на то что многие точки геометрически совпадают (на 4483 крыльях из нашего датасета медианное расстояние между гомологичными точками — 0 px), **нумерация и биологическое назначение различаются**:
- Алпатов L1 ≠ Тофильский L1
- Индексы Алпатова вычисляются по конкретным ID, формулы не работают на чужой нумерации
- Подменив одну схему другой, получим **тихую ошибку определения подвида**

Проект **строго разделяет** их: разные модели, разные профили, валидация при загрузке checkpoint'а проверяет соответствие n_points профилю.

## Архитектура моделей

Обе модели — **UNet с предсказанием тепловых карт** (heatmap regression). Архитектура одинакова, различается только число выходных каналов:

| Параметр | Значение |
|---|---|
| Энкодер | 5 conv-блоков (32→64→128→256→256 каналов через base_ch=48 → 48→96→192→384→384) |
| Декодер | 3 ConvTranspose с skip-connections до 1/4 разрешения |
| Выход | (K, H/4, W/4) тепловых карт, K = 12 или 19 |
| Нормализация | GroupNorm (32 группы) — устойчив на малых батчах |
| Активация | ReLU |
| Loss | MSE между предсказанной и эталонной (гауссиан σ=2.5) теплокартой |
| Sub-pixel decoding | Argmax + 3×3 weighted centroid в окрестности пика |

### Гиперпараметры обучения

| | Tofilski 19pt | Alpatov 12pt |
|---|---|---|
| Train / Val / Test | 6283 / 721 / 387 | 5904 / 686 / 345 |
| Эпох | 100 | 100 |
| Batch | 24 | 24 |
| Optimizer | AdamW (wd=1e-4) | AdamW |
| LR schedule | Cosine, peak 1.5e-3 | то же |
| Mixed precision | FP16 (AMP) | FP16 |
| Аугментации | Affine ±10°, scale ±8%, brightness ±15%, gaussNoise, blur | то же |
| Время на RTX 5080 | ~87 c / эпоха, ~2.4 ч total | ~87 c / эпоха, ~2.4 ч |

### Test-time augmentation (TTA)

При инференсе доступна опция `--tta`: модель прогоняется на оригинале + горизонтально отражённом изображении, теплокарты усредняются. На наших данных даёт +5–8% к точности при двукратном увеличении времени.

## Результаты валидации

### Tofilski 19-точечная

```
val_mean   = 1.81 px
val_median = 1.55 px
val_p90    = 2.61 px
test_mean  = 9.82 px  (в исходных пикселях оригинала)
test_median= 4.09 px
```

### Alpatov 12-точечная

```
val_mean   = 1.67 px
val_median = 1.53 px
val_p90    = 2.57 px
test_mean  = 9.17 px
test_median= 4.27 px
```

> **Замечание**. Validation metrics измерены в координатах входного тензора (256×512). Test metrics — в координатах оригинального изображения (∼1280×500), отсюда множитель ~2.5×. Обе оценки согласованы.

## Источники данных

- **realData** — собственная коллекция 7400+ крыльев с 2025–2026 годов, разметка экспертами по схемам 12 и 19 точек. Импорт из TPS-формата tpsDig2.
- **outData** — открытый датасет KZ-wing-images (Казахстан, 1067 крыльев, разметка DrawWing).
- **wings (1)** — 10 крыльев для интерактивного тестирования, ручная разметка.
