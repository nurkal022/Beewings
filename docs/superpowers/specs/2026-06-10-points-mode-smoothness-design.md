# Плавность режима «Точки»: async ML + стабильная панель — дизайн

**Дата:** 2026-06-10
**Статус:** утверждён, готов к плану

## 1. Задача

В режиме «Точки» (встроенный аннотатор):
- клик по выбору методики «деформирует» панель (содержимое не помещается по
  высоте, элементы плющатся при смене 12↔19 точек);
- внутренняя ML-кнопка грузит модель синхронно (~3 c) → UI зависает.

Цель: смена методики плавная (без деформации), ML без заморозки UI; переключение
методики Алпатов↔Тофильский сохраняется.

## 2. ML без заморозки

Новый `beewings/annotator/ml_worker.py` — `MLDetectWorker(QThread)`:
- вход: `checkpoint: Path`, `bgr: np.ndarray`, `tta: bool`, опц. уже загруженная
  модель;
- `run()`: загрузка модели (если не передана) + `predict(return_confidence=True)`;
  сигналы `done(dict, dict)` (pred, conf) и `failed(str)`.
- Загрузка/инференс — Qt-free логика берётся из `beewings.ml.inference`.

`AnnotatorWidget._run_ml_detect` переписывается на асинхронный путь:
1. валидация (как сейчас: ann/image/project не None; проверка схемы checkpoint);
2. заблокировать кнопку ML (`side.ml_btn`), статус «Определяю точки…»;
3. запустить `MLDetectWorker` (передавая кэш `_ml_model`, если совпадает ckpt);
4. по `done`: на главном потоке — применить точки (как сейчас: set_landmark,
   uncertain<0.45), `canvas.refresh_landmarks`, `side.refresh`, `_save_current`,
   статус с уверенностью; разблокировать кнопку; закэшировать модель из воркера;
5. по `failed`: сообщение, разблокировать кнопку.
Гард `sip.isdeleted(self)` (уже добавлен) защищает колбэки, если виджет закрыт.
Кэш модели: воркер возвращает загруженную модель (или используем уже кэш),
`_ml_model`/`_ml_ckpt_path` обновляются в колбэке `done`.

## 3. Стабильная боковая панель

`SidePanel` оборачивает свой контент в `QScrollArea`:
- внутренний контейнер с текущим вертикальным layout;
- `QScrollArea(widgetResizable=True)`, вертикальная прокрутка при нехватке высоты,
  горизонтальная выключена; панель получает разумную фикс/мин ширину.
- `methodology_info` (QLabel) — фикс. минимальная высота, чтобы смена текста при
  переключении методики не дёргала раскладку.
Результат: смена методики (разное число точек/длина подписи) не плющит элементы —
панель прокручивается.

## 4. Сохранение поведения

- Переключение методики Алпатов↔Тофильский работает как раньше (сигналы, combo).
- Крэш-гарды (`sip.isdeleted`) в слотах аннотатора, `SidePanel`, `canvas`
  остаются.
- Внешний вид/хоткеи не меняются, кроме того что ML теперь не блокирует UI.

## 5. Модули и тесты

- `beewings/annotator/ml_worker.py` — `MLDetectWorker`.
- `beewings/annotator/annotator_widget.py` — async `_run_ml_detect` + колбэки.
- `beewings/annotator/side_panel.py` — `QScrollArea`-обёртка, фикс высоты инфо.
- Тесты (headless):
  - `MLDetectWorker.run()` синхронно (в тесте вызвать `.run()`) даёт pred/conf на
    реальном чекпоинте; `@skipif` если `checkpoints/alpatov12.pt` нет.
  - `SidePanel` строится; `self.list` доступен; смена методики
    (`set_methodology`/`set_profile`) не роняет; панель содержит `QScrollArea`.
  - регрессия: существующие крэш-гарды и smoke-тесты зелёные.
