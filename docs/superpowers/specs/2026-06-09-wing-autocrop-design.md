# Авто-нарезка крыльев со скана — `beewings-crop`

**Дата:** 2026-06-09
**Статус:** утверждён дизайн, готов к плану реализации

## 1. Проблема

Первый этап анализа морфометрии — нарезка одного большого скана (стекло с
20–50 крыльями + рукописная этикетка) на отдельные изображения крыльев. Сейчас
это делается **вручную** (видно по файлам `04401_crop_0.jpg … _crop_27.jpg` +
`.tps` рядом с исходным сканом `04401.jpg` 11232×4378). Нужно автоматизировать
именно этот шаг: скан → набор отдельных крыльев, готовых для разметки точек
(`beewings-ml-batch`).

## 2. Характеристики данных (по 4 сканам из разных папок)

- Разрешение большое: 11000–14000 px по ширине.
- Фон светлый и однородный (белый или кремовый).
- Крылья — полупрозрачный «загар» с тёмными жилками, отбрасывают лёгкую тень.
- Крылья **не соприкасаются**, лежат регулярной сеткой (≈5 столбцов × N строк).
- Ориентация крыльев **одинаковая внутри одного скана**, но **разная между
  сканами**: вертикально (Клат, Мирных), по диагонали (Владик, Красон).
- Этикетка с рукописью **всегда слева**, отделена краем стекла.
- Готовые ручные кропы — горизонтальные ~1300×550 px, переменного размера
  (плотный bbox вокруг крыла), основание (узкое тёмное сочленение) слева.

## 3. Выбранный подход

**Гибрид: классический CV (OpenCV) + сеточный приор.** Без обучения и разметки,
работает сразу на этих чистых сканах, каждый рез проверяется визуально через
debug-оверлей. Точка расширения на обученный детектор (YOLO/DeepWings) заложена
на будущее (грязные сканы, слипшиеся крылья), но сейчас — YAGNI.

Обоснование research: DeepWings© использует CNN-детектор крыльев (mAP 0.975) +
U-Net для точек; есть работа «Fully automatic segmentation of bee wing images».
Направление проверенное, но для чистых сеточных сканов классический CV
достаточен и проще в отладке.

## 4. Архитектура

Новый подпакет `beewings/segment/` + CLI `beewings-crop` (по аналогии с
`beewings-ml-batch`). Каждый модуль — одна ответственность, тестируется отдельно.

```
beewings/segment/
├── __init__.py
├── slide.py        # детекция стекла + области этикетки (слева)
├── wings.py        # маска крыльев → контуры → bbox по каждому крылу
├── layout.py       # кластеризация в строки/столбцы → порядок нумерации
├── crop.py         # вырезка + опц. поворот в каноническую горизонталь
├── debug.py        # оверлей: рамки, номера, рамка этикетки
└── cli.py          # entry point beewings-crop
```

Выход (`<scan>_crop_N.jpg`) напрямую подаётся в существующий `beewings-ml-batch`.

## 5. Пайплайн

1. **Загрузка.** Скан читается из оригинала; для детекции делается уменьшенная
   рабочая копия (скорость). Финальная вырезка — из оригинала (без потери
   качества). Все координаты масштабируются обратно.
2. **Этикетка** (`slide.py`). Находим левый блок с рукописью (высокая локальная
   дисперсия / насыщенный цвет маркера) → bbox. Сохраняем как `<scan>_label.jpg`
   и **закрываем сплошным прямоугольником** в рабочей маске, чтобы не мешала
   детекции крыльев. Авто-оценка цвета фона по углам скана.
3. **Маска крыльев** (`wings.py`). Перевод в Lab; фон яркий/однородный → порог по
   каналу L (крылья темнее + тёмные жилки) c авто-порогом (Otsu/относительно
   фона); морфологическое закрытие, чтобы жилки + мембрана слились в один блоб на
   крыло.
4. **Контуры/компоненты.** `findContours` / connected components → фильтр по
   площади (`--min-area-frac` от площади скана) — отсекаем пылинки, мусор и
   остаток этикетки.
5. **Порядок** (`layout.py`). Кластеризуем центроиды по Y в строки, внутри строки
   сортируем по X → нумерация в порядке чтения `_crop_0,1,2,…`. Сеточный приор
   даёт ожидаемые центры ячеек.
6. **Вырезка** (`crop.py`). bbox + поля (`--margin`, по умолчанию 0.10), вырезка
   из оригинала. Опционально `--rotate-canonical`: поворот по главной оси (PCA)
   в горизонталь, основание слева (узкий тёмный конец — слева, широкий кончик —
   справа; определяется по профилю ширины маски вдоль главной оси).
7. **Debug-оверлей** (`debug.py`). На уменьшенном скане — все рамки + номера +
   рамка этикетки. Позволяет проверить каждый рез **до** записи (`--dry-run`).

## 6. Этикетка

- `<scan>_label.jpg` — отдельный файл с областью рукописи.
- Область маскируется (сплошной прямоугольник) перед детекцией крыльев.
- OCR рукописи — **не в этой итерации** (рукописный русский ненадёжен). Заложить
  флаг `--ocr-label` как точку расширения на будущее.

## 7. CLI

```bash
# один скан
beewings-crop --input "скан/Клат/8.jpg" --out crops/Клат --debug

# вся папка рекурсивно
beewings-crop --input "скан/" --out crops/ --recursive --debug

# кропы рядом со сканом (как в ручном процессе)
beewings-crop --input "скан/Клат/8.jpg" --inplace
```

Параметры:

| Флаг | Назначение | Default |
|---|---|---|
| `--input` | файл скана или папка | (обяз.) |
| `--out` | папка вывода (зеркальная структура) | (обяз., если не `--inplace`) |
| `--inplace` | писать кропы рядом со сканом | off |
| `--recursive` | обходить вложенные папки | off |
| `--margin` | доля полей вокруг bbox | 0.10 |
| `--min-area-frac` | мин. площадь крыла (доля площади скана) | 0.0003 |
| `--rotate-canonical` | поворот в горизонталь, основание слева | **off** (рекомендуется on для ML) |
| `--debug` | сохранять `<scan>_debug.jpg` оверлей | off |
| `--dry-run` | только оверлей, без записи кропов | off |
| `--ocr-label` | (задел) OCR этикетки | off |

## 8. Структура вывода

Зеркало входа (при `--out`):

```
crops/Клат/
├── 8_crop_0.jpg … 8_crop_49.jpg
├── 8_label.jpg
└── 8_debug.jpg          # только при --debug
```

При `--inplace` — те же файлы рядом со сканом (совместимо с текущим ручным
процессом `<scan>_crop_N.jpg`).

## 9. Краевые случаи

- **Слипшиеся крылья** → watershed-разделение по сеточному приору (ожидаемые
  центры ячеек).
- **Бледный кончик обрезается** → морфологическое закрытие + запас полей;
  debug-оверлей это покажет.
- **Разный фон** (белый/кремовый) → авто-оценка фона по углам скана.
- **Число крыльев ≠ ожидаемой сетке** → предупреждение в логе (не падаем).
- **Пустой/битый скан** → понятная ошибка, не падаем на остальных файлах при
  `--recursive`.

## 10. Тестирование

- Юнит-тесты модулей `slide`/`wings`/`layout`/`crop` на синтетических входах.
- Интеграционные тесты на 3 эталонных сканах из разных папок
  (Клат = 50 крыльев, Владик/04401 = 28, Мирных) с проверками:
  - число найденных крыльев совпадает с ожидаемым;
  - область этикетки исключена из кропов;
  - все кропы непустые и в пределах размеров скана.
- Visual-проверка через `--debug` на ~5 сканах разных типов.

## 11. Вне scope (на будущее)

- OCR рукописной этикетки (`--ocr-label`).
- Обученный детектор (YOLO/DeepWings) для грязных/слипшихся сканов.
- Генерация `.tps` (точки ставит существующий `beewings-ml-batch`).
