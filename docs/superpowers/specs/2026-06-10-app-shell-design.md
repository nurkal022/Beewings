# Единое приложение BeeWings: Home → Проект → режимы — дизайн

**Дата:** 2026-06-10
**Статус:** утверждён, готов к плану

## 1. Задача (смена философии)

Сейчас `beewings` открывает сразу аннотатор точек, а нарезка — отдельный мастер.
Нужно сделать единое приложение:

- На старте — **Home** (менеджер проектов): история недавних папок + открыть новую.
- Открытая папка = **проект** с несколькими **сплитами** (большие сканы).
- Внутри проекта — **вкладки сверху**: «Нарезка», «Точки», «Экспорт». Текущий
  аннотатор становится вкладкой «Точки» (встроен как режим, не отдельное окно).
- Удобно и красиво: ничего лишнего, единый стиль.

## 2. Точка входа

`beewings` запускает `beewings.app.app:main`, который показывает **Home**.
`beewings-pipeline` остаётся алиасом на тот же `main` (обратная совместимость).
Standalone-аннотатор (`MainWindow`) сохраняется работоспособным для отладки, но
не является точкой входа.

## 3. Home (стартовый экран)

`HomeScreen(QWidget)`:
- Заголовок + кнопка **«Открыть папку…»** (QFileDialog → каталог).
- Список/сетка **недавних проектов** карточками: имя папки, путь, строка
  прогресса (`нарезано N/M · точек K`), дата последнего открытия. Клик по
  карточке открывает проект. Карточка имеет кнопку «убрать из истории».
- Пусто → подсказка «Откройте папку со сканами, чтобы начать».

История: `beewings/app/recents.py` — Qt-free. Файл `~/.beewings/recents.json`:
```json
{"version": 1, "items": [
  {"path": "/abs/path", "name": "Клат", "opened_at": "2026-06-10T12:00:00",
   "n_splits": 3, "n_cropped": 3, "n_landmarked": 2}
]}
```
API: `load_recents()`, `add_recent(path, stats)` (dedup по path, самый свежий
сверху, обрезка до 20), `remove_recent(path)`, `save_recents(items)`. Время
передаётся аргументом (без скрытого `datetime.now()` в чистой функции — для
тестируемости), записывается вызывающим слоем.

## 4. Проект = папка сплитов

Открытие папки создаёт/загружает `CropProject` (модель уже есть). Сплиты —
изображения **верхнего уровня** папки (вложенные папки не обходим). Состояние и
результаты — в самой папке: `project.json`, `crops/`, `export/`. При открытии
существующей папки без `project.json` он создаётся, сплиты заполняются из
найденных изображений; при наличии — загружается.

`CropProject` расширяется методом-фабрикой `open_folder(folder) -> CropProject`
(загрузить project.json или создать из изображений верхнего уровня) и методом
`progress() -> dict` (`n_splits`, `n_cropped`, `n_landmarked`) для Home/карточек.

## 5. Окно проекта с вкладками

`ProjectWindow(QMainWindow)`:
- Верхняя панель: имя проекта · кнопка **«← Дом»** · **⚙ настройки**
  (профиль / margin / delta / label-frac — пишет в `project.settings`).
- `QTabWidget` со вкладками (виджеты получают общий `ctx={"project":...}`):
  1. **Нарезка** — `CropTab` = текущая логика `crop_page` (список сплитов +
     `BoxEditorCanvas` + Авто/Пересоздать/Отмена, ошибки и прогресс).
  2. **Точки** — `LandmarkTab`: слева список сплитов; выбор сплита грузит его
     `crops_dir` во встроенный `AnnotatorWidget`; кнопка «🧠 Расставить точки
     (ML)» (LandmarkWorker по этому сплиту), ручная правка через аннотатор.
  3. **Экспорт** — `ExportTab` = текущая логика `export_page`.
- Закрытие/«← Дом» сохраняет проект и обновляет запись в истории.

## 6. Рефакторинг аннотатора (ключевая часть)

Вынести редактор точек из `MainWindow(QMainWindow)` в самостоятельный
**`AnnotatorWidget(QWidget)`** (`beewings/annotator/annotator_widget.py`):
канвас + боковые панели + список изображений + вся логика (загрузка/сохранение
аннотаций, ML-кнопка, хоткеи, навигация, экспорт-методы). Публичный API:
`load_folder(path: Path)`, и виджет должен работать без меню (хоткеи и кнопки
встроены).

`MainWindow` становится тонкой обёрткой: создаёт `AnnotatorWidget`, добавляет
меню «Файл/Вид» поверх (для standalone-режима), делегирует `load_folder`. Так
`beewings`-как-аннотатор и встраивание во вкладку используют один и тот же код.

Подход безопасный: сначала извлечь виджет и сделать `MainWindow` обёрткой
(поведение standalone сохраняется, проверяется тестом-смоком и реальным
запуском), затем встроить `AnnotatorWidget` во вкладку «Точки».

## 7. Полировка (стиль)

`beewings/app/style.py` — функция `apply_style(app)` с QSS: согласованные цвета,
отступы, скруглённые кнопки, выделение активной вкладки, карточки Home с рамкой и
hover. Чистый Qt stylesheet, без зависимостей. Применяется в `app.main()`.

## 8. Модули

```
beewings/app/
├── __init__.py
├── recents.py         # история проектов (Qt-free)
├── style.py           # apply_style(app) — QSS
├── home.py            # HomeScreen(QWidget)
├── project_window.py  # ProjectWindow(QMainWindow) + вкладки CropTab/LandmarkTab/ExportTab
└── app.py             # main(): Home -> ProjectWindow

beewings/annotator/
├── annotator_widget.py  # AnnotatorWidget(QWidget) — вынесенный редактор точек
└── main_window.py       # тонкая обёртка над AnnotatorWidget (standalone)
```
Вкладки переиспользуют `beewings/pipeline/`: `project` (модель), `box_canvas`,
`workers` (CropWorker/LandmarkWorker), `export`. Логика вкладок «Нарезка»/«Экспорт»
переносится из `pipeline/pages/{crop_page,export_page}.py` (старые
`select_page`/`landmark_page`/`wizard.py` замещаются Home/вкладками — удаляются).

## 9. Тестирование

- `recents.py` — Qt-free юнит: добавление, дедуп по path, порядок (свежее
  сверху), обрезка до 20, remove, round-trip JSON.
- `CropProject.open_folder` / `progress()` — юнит на синтетической папке сканов.
- Headless-smoke (offscreen): `HomeScreen` строится и рендерит recents;
  `ProjectWindow` имеет 3 вкладки; `AnnotatorWidget` грузит папку крыльев;
  `MainWindow` (обёртка) по-прежнему открывается.
- e2e (headless): `open_folder` → авто-нарезка+recrop (CropWorker.run) →
  export_protocol — без падений, файлы на месте.

## 10. Вне scope

- Облачная синхронизация истории.
- Параллельная обработка нескольких сплитов одновременно.
- OCR этикетки (как и раньше).
