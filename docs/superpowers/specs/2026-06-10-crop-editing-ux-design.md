# Улучшение редактирования нарезки — дизайн

**Дата:** 2026-06-10
**Статус:** утверждён, готов к плану

## 1. Задача

Сделать вкладку «Нарезка» удобной для ручной правки рамок:
- удобный ресайз (видимые маркеры, ручки сторон, клавиатура);
- удаление рамок;
- панель со списком найденных объектов для выбранного скана, синхронизированная
  с канвасом;
- кнопка добавления этикетки, если она не найдена.

## 2. Панель «Найденные объекты»

В `CropPage` добавляется средний столбец: `[сплиты] [объекты] [канвас]`.
Панель объектов:
- `QListWidget` строк «Крыло 1 … N» по `wing_boxes` выбранного скана; обновляется
  при выборе сплита и при изменениях рамок.
- Двусторонняя синхронизация: выбор строки → `canvas.select_box(idx)` (подсветка);
  `canvas.selectionChanged(idx)` → выделение строки. `idx == -1` — снять выделение.
- Кнопка «Удалить» удаляет выделенную рамку (`canvas.delete_box(idx)`).
- Блок этикетки: метка статуса «Этикетка: есть / не найдена»; кнопка
  «Добавить этикетку» (видна, когда `label_box is None`) включает режим рисования
  (`canvas.begin_label_draw()`); кнопка «Удалить этикетку» (когда есть) →
  `canvas.clear_label()`. Изменения пишутся в `project.json` (через существующий
  `_sync_boxes`).

## 3. Ресайз и выделение (box_canvas + geometry)

- **Выделение:** клик по рамке выделяет её (`_selected: int`), рисуется толще/ярче;
  сигнал `selectionChanged(int)`; пустой клик снимает выделение (-1).
- **Видимые маркеры** у выделенной рамки: 4 угла + 4 середины сторон (8 квадратов).
- **geometry.py:** `hit_test` и `resize_box` получают ручки сторон `n/s/e/w`
  (сейчас только `nw/ne/sw/se` + `move`). `resize_box`:
  - `n`: `(x, y+dy, w, h-dy)`; `s`: `(x, y, w, h+dy)`;
  - `w`: `(x+dx, y, w-dx, h)`; `e`: `(x, y, w+dx, h)` — все через `normalize_box`.
- **Клавиатура** (когда есть выделение, фокус на канвасе): стрелки — сдвиг рамки на
  1px; Shift+стрелки — на 10px; Del/Backspace — удалить выделенную.
- **Курсоры:** над угловой ручкой — диагональный, над боковой — гориз./верт.,
  над телом — рука/перемещение.

## 4. Режим добавления этикетки

`canvas.begin_label_draw()` → следующая протяжка ЛКМ создаёт красную рамку
этикетки (а не крыло); по завершении режим выключается, эмитится `boxesChanged`.
Существующие `make_label(idx)` (сделать этикеткой из крыла) и `clear_label()`
сохраняются/добавляются. Этикетка по-прежнему исключается из нарезки.

## 5. Модули и интерфейсы

- `beewings/pipeline/geometry.py` — добавить `n/s/e/w` в `hit_test` (середины
  сторон в пределах `handle_px`) и в `resize_box`.
- `beewings/pipeline/box_canvas.py`:
  - состояние `_selected: int = -1`; сигнал `selectionChanged = pyqtSignal(int)`;
  - `select_box(idx)`, `selected()` ;
  - отрисовка выделения + 8 маркеров; курсоры в `mouseMoveEvent` (hover);
  - `begin_label_draw()` + флаг `_label_mode`; `clear_label()`;
  - `keyPressEvent` (стрелки/Shift/Del) с `setFocusPolicy(StrongFocus)`;
  - эмиссия `selectionChanged` при выборе/снятии.
- `beewings/pipeline/pages/crop_page.py` — средний столбец (objects `QListWidget`
  + «Удалить» + статус/кнопки этикетки), методы `_refresh_objects()`,
  `_on_object_selected`, `_on_canvas_selection`, `_add_label`, `_remove_label`;
  обновлять список на `enter`/`_show_scan`/`boxesChanged`.

## 6. Тесты

- `geometry`: hit_test находит `n/s/e/w` на серединах сторон; resize по каждой из
  4 сторон даёт корректный bbox; угловые/move без регрессий.
- `box_canvas` (headless): `select_box`/`selected`/`selectionChanged`;
  `begin_label_draw` → программная имитация создаёт `label_box`; `clear_label`;
  удаление выделенной.
- `crop_page` (headless): список объектов = числу `wing_boxes`; выбор строки →
  `canvas.selected()` совпадает; «Добавить этикетку» доступна только без этикетки.

## 7. Вне scope

- Мультивыбор рамок.
- Drag-reorder списка объектов (нумерация остаётся порядком чтения).
